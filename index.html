✦How it works

Six doors, one platform

Every visitor arrives through one of six doors. The request meets the edge, is checked at the gateway, is handled by one of eighteen modules, and lands in a database that shows a campus only its own rows.

Access via
Public website + admission portal Student portal Parent portal Faculty portal Admin and staff console Mobile app — QR scan, GPS
↓
Edge
Internet CDN and WAF — static assets, tenant subdomains API gateway — TLS, rate limit, tenant resolver, JWT pre-check
↓
Application
Auth and IAM Tenancy Admissions Students Faculty and HR Academics Timetable Attendance Exams and results Fees and payments Library Hostel Transport LMS-lite Communication Reports and BI Files Audit
↓
Data
PostgreSQL 16 — row-level security Cache and QR tokens Background jobs Search index Object storage

✦ India-specific integrations

  • DigiLocker — document verification

  • GST invoicing — receipts

  • Regional language support
